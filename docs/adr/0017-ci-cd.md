# 0017. CI gates and tag-triggered delivery

- Status: Accepted
- Date: 2026-10-19
- Decided by: Priyanshu Kumar, harness round 2 (R3)

## Decision

Blocking checks, built on `chore/ci`:

- `api`: ruff lint and format, pyright strict on `src/`, pytest with Postgres and Redis service containers, coverage ≥ 80%, migration round trip, immutable migrations, no SQL outside `repo/`
- `contract`: OpenAPI drift, oasdiff breaking changes against `master`, Spectral lint, SDK drift plus `tsc --noEmit`
- `web`: demo typecheck, Biome lint, build
- `security`: gitleaks, pip-audit and `pnpm audit` (high), CodeQL for Python and TypeScript
- `meta`: actionlint, conventional commit lint on every commit, Docker image build

Non-blocking: nightly k6 smoke reporting p95. Dependabot weekly for pip, npm and actions. Delivery on a release tag: push the image to GHCR and attach the SDK to a GitHub Release. No npm publish.

## Consequences

The repo is public, so secret scanning runs on every push. Nothing is deployed.
